# 饥荒大乱斗 · Don't Starve LOL

饥荒画风的第一人称 RPG 生存游戏:选一位 LOL 式英雄,在昼夜交替的荒野中战斗、升级、探索奇遇,并在第 3 天夜晚击败苏醒的树精巨人。

所有美术均为 Canvas 程序化手绘(歪扭墨线 + 暗淡色调),音效为 WebAudio 合成,无任何外部素材。

## 运行

```bash
npm install
npm run dev
```

打开 http://localhost:5173 即可游玩。

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD | 移动 |
| 鼠标 | 视角(点击屏幕锁定) |
| 左键 | 普通攻击(可按住连发) |
| Q / E / Shift / R | 四个技能(R 为大招,6 级解锁) |
| 1 ~ 4 | 为对应技能加点 |
| F | 与奇遇互动 |

## 英雄

- **灰烬法师 · 薇洛**(远程法术):烈焰火球 / 冰霜新星 / 奥术闪现 / 焚天陨星
- **荒野战士 · 布洛克**(近战坦克):裂地重斩 / 战地怒吼(护盾)/ 蛮牛冲锋 / 血怒旋风
- **暗影刺客 · 鸦**(近战爆发):影袭(偷袭必暴击)/ 烟雾遁形(潜行)/ 鬼步 / 绝命莲华

## 玩法要点

- **昼夜循环**:白昼→黄昏→黑夜。夜晚视野变暗、暗影怪出没;篝火旁安全且缓慢回血,暗影不敢靠近。
- **升级**:击杀怪物掉落经验球和金币。升级得技能点,按 1~4 加点;6 级解锁大招。
- **奇遇**(按 F 互动):
  - 宝箱 —— 金币、增益道具,也可能是宝箱怪!
  - 神秘商人 —— 花金币买药剂和永久属性(越买越贵)
  - 远古祭坛 —— 献祭生命换取永久祝福
  - 幽光之井 —— 投币许愿,效果随机
  - 试炼石碑 —— 存活 25 秒,赢取厚礼
- **随机事件**:第 2 天起会有猎犬群袭击;沼泽里潜伏着高伤害触手。
- **Boss**:第 3 天夜晚树精巨人苏醒,会召唤爪牙。击败它即获胜(胜利后可继续游荡)。
