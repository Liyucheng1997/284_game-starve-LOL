# 饥荒大乱斗 · Don't Starve LOL

饥荒画风的**第一人称 3v3 MOBA**:选一位英雄,与两名 AI 队友组成「营火同盟」,在三路兵线的永夜峡谷中对抗「暗影议会」,推倒敌方的暗影王座即可获胜。

所有美术均为 Canvas 程序化手绘(歪扭墨线 + 暗淡色调),音效为 WebAudio 合成,无任何外部素材。

## 运行

```bash
npm install
npm run dev
```

打开 http://localhost:5173 即可游玩。

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD | 移动 |
| 鼠标 | 视角(点击屏幕锁定) |
| 左键 | 普通攻击(可按住连发,唯一能攻击建筑的方式) |
| Q / E / Shift / R | 四个技能 |
| 1 ~ 4 | 为对应技能加点 |
| B | 回城(6 秒读条,移动/攻击/受伤会打断) |
| P | 商店(仅在泉水附近或阵亡时可购买) |
| F | 使用治疗药膏 |
| Tab(按住) | 战绩表 |

## 对局规则

- **地图**:200×200 的方形峡谷,我方基地在左下、敌方在右上;上 / 中 / 下三条兵线,中间一条河道,两侧是树林组成的野区。
- **胜负**:摧毁敌方「暗影王座」获胜;我方「永恒篝火」被摧毁即失败。
- **防御塔**:每路外塔 + 内塔。必须先拆外塔才能攻击内塔;任意一座内塔倒下后基地水晶才会失去保护。塔优先攻击小兵,但**你在塔下攻击敌方英雄会立刻被塔锁定**,连续命中伤害递增。靠近敌塔会显示红色攻击范围圈。
- **兵线**:每 30 秒每路出一波小兵(3 近战 + 2 远程,每第 3 波附带攻城单位),越往后越强。敌方内塔被拆后,该路每波都带攻城兵。
- **经济**:只有**补刀**(最后一击)才拿金币;附近阵亡的敌方单位都会分享经验。另有每秒 2 金的被动收入。击杀英雄 300 金,助攻 120 金。
- **死亡**:阵亡后按等级计算复活时间,在泉水复活。泉水会快速回复己方,并灼烧闯入的敌人。
- **视野**:敌方英雄只有在我方单位视野内才会显示(小地图同步)。夜晚视野缩小。
- **难度**:新手 / 老手 / 噩梦,影响敌方 AI 的伤害、经济、反应速度、施法频率与越塔倾向。

## 野区

| 营地 | 奖励 |
| --- | --- |
| 冰霜猎犬王 | 「冰霜之心」:冷却缩减 +15%,法力回复 ×3(90 秒) |
| 火焰猎犬王 | 「炎魔之心」:普攻灼烧并减速(90 秒) |
| 蜘蛛巢 / 猎犬丘 | 金币与经验 |
| 触手沼泽(下河道) | 会攻击一切靠近的单位 |
| 树精巨人(上河道,7:00 刷新) | 全队「树精祝福」:攻击 +30、回复加快、之后的兵线被强化(150 秒) |

击杀持有红/蓝增益的英雄会继承其增益。

## 英雄

- **灰烬法师 · 薇洛**(远程法术):烈焰火球 / 冰霜新星 / 奥术闪现 / 焚天陨星
- **荒野战士 · 布洛克**(近战坦克):裂地重斩 / 战地怒吼(护盾)/ 蛮牛冲锋 / 血怒旋风
- **暗影刺客 · 鸦**(近战爆发):影袭(背刺或潜行必暴击)/ 烟雾遁形(潜行)/ 鬼步 / 绝命莲华

你固定走中路,对面是同一英雄的「暗影」版本;另外两名英雄作为 AI 队友去上、下路,敌方三名 AI 各守一路。技能等级不能超过英雄等级的一半,大招在 6 / 11 / 16 级可升级。

## AI

敌我 AI 英雄会:跟随兵线补刀、根据血量/等级/人数判断换血或撤退、避免无兵线时越塔、被塔锁定立即撤出、残血喝药或回城、在泉水按出装路线购物、用技能连招(预判走位的火球与陨石、冲锋开团、潜行逃生),并在人数优势时去打树精巨人。

## 代码结构

| 文件 | 内容 |
| --- | --- |
| `src/config.js` | 地图布局、兵线路径、塔/野怪/小兵数值、装备、难度 |
| `src/game.js` | 3D 世界、统一的单位与伤害结算、兵线/塔/野怪逻辑、经济与复活 |
| `src/heroai.js` | 英雄 AI(对线、补刀、换血、撤退、技能) |
| `src/heroes.js` | 英雄属性成长、技能(玩家施放版本)与 AI 出装 |
| `src/ui.js` | HUD、小地图、商店、战绩表、击杀播报 |
| `src/textures.js` / `src/textures_moba.js` | 程序化手绘贴图 |
